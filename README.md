# smart-indoor-farming

Project ini merupakan sistem smart indoor farming berbasis IoT menggunakan ESP32 yang terintegrasi dengan Firebase untuk monitoring dan kontrol secara real-time.

## Fitur
- Monitoring suhu & kelembapan (DHT11)
- Monitoring cahaya (BH1750)
- Monitoring ketinggian air (Ultrasonic)
- Monitoring nutrisi (Analog & TDS)
- Kontrol pompa (Analog & TDS)
- Kontrol grow light (Manual & Auto)
- Notifikasi kondisi abnormal

## Struktur Project
- IoTBoard1 = kode untuk suhu dan kelembapan, cahaya, ketinggian air, nutrisi, serta grow light
- IoTBoard2 = kode untuk pompa dan tds meter
